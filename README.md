# Web Page Summarizer - Local AI（Chrome拡張）

表示中のWebページの本文を抽出し、Chrome内蔵AI（Gemini Nano / Summarizer API）で要約して右のサイドパネルに表示します。
外部サーバーへの送信は一切なく、要約はすべて端末内で完結します。

## インストール（ローカル読み込み）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダ（`page-summarizer`）を選択
4. ツールバーのアイコン（青いバー4本）をクリック → 右にサイドパネルが開く
5. 要約したいページを開いた状態で「要約する」を押す

## 内蔵AIの準備

Summarizer API には要件があります。使えない場合はパネル上部に赤いランプとメッセージが出ます。

- Chrome 138 以降（デスクトップ版のみ、モバイル不可）
- 空きストレージ 22GB以上 / VRAM 4GB以上 / 従量課金でないネットワーク
- 初回のみ Gemini Nano（約2GB）のダウンロードが必要。「要約する」を押すと開始し、進捗バーが出ます

うまく認識されない場合は以下を有効化して Chrome を再起動:

- `chrome://flags/#summarization-api-for-gemini-nano` → Enabled
- `chrome://flags/#optimization-guide-on-device-model` → Enabled BypassPerfRequirement
- ダウンロード状況は `chrome://on-device-internals` で確認できます

## 使い方

サイドパネル左上の「要約する」を押すだけです。長さ・形式は設定画面（パネル右上の歯車、または
`chrome://extensions` の「拡張機能のオプション」）で変更でき、変更は即保存されます。

- **パネルを開いたら自動で要約する**: 既定でオン。オフにすると「要約する」を押したときだけ実行
- **要約の言語**: English / 日本語 / 中文（简体）。既定はブラウザのUI言語（対応外は英語）
- **要約の長さ**: 短い（既定） / ふつう / 長い
- **要約の形式**: 箇条書き / TL;DR / ティザー / 見出し
- 設定は `chrome.storage.sync` に保存され、同じGoogleアカウントの他のChromeにも同期されます
- 長いページは自動で分割要約 → 統合要約されます

要約は**体言止め**で出力されます。主語（誰が・何を）と接続詞は省略せず、項目単体で意味が通る形にしています。
AIへの指示（`SUMMARY_STYLE`）に加え、
表示時にも `tidyLine()` が行頭記号・句点・「です／である／となっています」などの語尾を落として整形します。
文体を変えたい場合は `sidepanel.js` の `SUMMARY_STYLE`（言語ごとに定義）を書き換えてください。
設定画面とサイドパネルのUI文言は日本語固定です（変わるのは要約文の言語のみ）。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | MV3 マニフェスト（sidePanel / scripting / activeTab / storage） |
| `background.js` | アイコンのクリックを受けてサイドパネルを開く（activeTab付与のため） |
| `sidepanel.html/.css` | パネルのUI。左上に要約ボタン、右上に設定ボタン |
| `sidepanel.js` | 本文抽出スクリプトの注入 + Summarizer API 呼び出し |
| `options.html/.css/.js` | 設定画面（要約の長さ・形式） |
| `settings.js` | 設定の既定値と読み書き。ブラウザ言語の判定もここ |
| `icons/` | 16 / 48 / 128px アイコン |

## 制限

- `chrome://` や Chrome ウェブストアなど、拡張がスクリプトを注入できないページでは動作しません
- 権限ダイアログは既定では表示されません。ツールバーのアイコンをクリックすると `activeTab` が付与され、
  そのタブの本文だけを読み取ります。タブを切り替えたら、アイコンを押し直してパネルを開き直してください
- 押し直しを省きたい場合は、設定画面の「すべてのサイトで許可する」をオンにします（このときだけChromeの
  権限ダイアログが出ます）。オフに戻せば権限も取り消されます
- 本文抽出は `article` / `main` などを優先するヒューリスティックのため、特殊なレイアウトのサイトでは精度が落ちます
- Gemini Nano の日本語出力品質はクラウドLLMより劣ります（`outputLanguage: 'ja'` が拒否された場合は既定言語で再試行します）
